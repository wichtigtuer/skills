# Skills

A collection of agent skills for common development workflows.

## Skills

- **git-worktrees** — working with git worktrees
- **github-cli** — patterns for invoking the GitHub CLI (`gh`)
- **github-issues-workflow** — GitHub issues workflow and planning references
- **modern-css** — modern CSS techniques
- **node-native-tests** — Node.js native test runner patterns
- **review-architecture-docs** — reviewing architecture documentation
- **review-function** — reviewing individual functions
- **sdte-loop** — spec-driven test-evaluate loop
- **web-components** — building web components
- **web-security** — web security best practices

## Usage

Skills live in `skills/<name>/` with a `SKILL.md` describing usage and optional reference files. Load a skill by reading its `SKILL.md` when the task matches its description.
